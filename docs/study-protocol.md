# 扩展实验协议（运行前固定）

1. 从全部 5,328 个 PCAP 各读取最多前 2,048 条原始记录。开发集取已有 533 个文件标识，确认集是其严格补集；不是独立外部数据。主要任务为固定包预算下的会话来源分类。原 533 场的 EOF 和 2048 预算额外作配对比较。不得用该比较声称全库 EOF 结果。
2. 固定 HGB（原有超参数）。开发集五折复用分箱视图，重训各特征族：原始箱、跨箱统计、顺序标志、偏离、风格，逐族移除；另比较仅 103 个加权均值、仅 90 个顺序标志、仅 11 个字段比例、均值+标志、均值+标志+风格。单独测试去掉所有显式顺序对列及删掉亦编码顺序的偏离/风格/切换列的保守版本。这里的区别是输入关联，不是网络行为机制的因果效应。
3. 精简规则：开发集前缀上预设六个候选（字段均值11、标志90、均值103、均值+标志193、均值+标志+风格217、跨箱统计+标志502）。在与完整 Dist 相同可评分样本上，选 AP 距完整不超过 0.015 的最低维候选；若无满足者保留完整。先记录选择，再查看确认结果，不改阈值。最终列名、原始列号可导出。
4. 确认主实验：在未用于模型/特征选择的其余文件上重新运行原有固定五折协议（三折训练、一折校准工作点、一折测试），报告预选模型、完整 Dist HGB/ET、线性、传统 GBDT、行为 HGB；不能当作已训练模型迁移或跨题目验证。负对照：在确认集各折内固定打乱标签一次，重训与评估，检查 AP 是否靠近正类比例；这不是置换显著性检验。额外审计完全相同的特征向量跨折出现情况。
5. 主指标为共同可评分集 AP，辅报各自覆盖率、AP、ROC-AUC、F1、MCC、Brier、验证目标 1/5% 下实际 FPR/TPR、混淆数及各折结果。比较精简与完整的 AP 差值采用同一批折外预测、按折及标签分层的会话级配对 bootstrap（1000 次，条件区间，不含重训/题目聚类误差）。缺少题目、操作者、框架 ID，不声称跨域泛化或通用 LLM 指纹。明确报告未达容差的结果。
