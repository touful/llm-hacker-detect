## 固定配置

两路分别为 145 维多视图聚合向量（conv）和 2,190 维请求分箱向量（dist）。全空训练列删除，非 HGB 模型其余缺失以训练列中位数填补，HGB 原生处理；线性、距离、核与朴素贝叶斯模型使用训练数据标准化。SVM 的 sigmoid 概率校准在三个训练折组成的数据内部完成，不使用外部验证/测试标签。

|标记|分类器与设置|
|---|---|
|linear|L2 逻辑回归，C=1，liblinear|
|gnb|高斯朴素贝叶斯，var_smoothing=1e-6|
|knn|7 近邻，欧氏距离，距离加权|
|rbf|RBF-SVM，C=1，gamma=scale，内部三折 sigmoid 校准|
|cart|单决策树，深度≤6，最小叶5|
|rf|随机森林，160 棵，sqrt 候选列，最小叶3|
|et|极端随机树，96 棵，每次抽取 80% 候选列，最小叶5|
|ada|AdaBoost，80 个深度1的树桩，最小叶5，学习率0.5|
|gbdt|经典梯度提升，80 棵，深度2，最小叶8，学习率0.05|
|hgb|直方图梯度提升，80 轮，15 叶，最小叶20，学习率0.05，L2=1|

**复跑（在 attribution 目录）：** 使用 README 的参考解释器运行 `& $py -m agenttrace evaluate runs/full-session-pilot.npz --classical --out runs/classical-repro`，使用新输出目录。原始逐折指标、概率、混淆矩阵与阈值在 runs/classical-reference/。另以 sklearn 1.9.0 复算于 runs/classical-matrix/；本文不混用两个版本的数值。
