# 有向字段对与无向共现的配对消融

在 4,549 场共同可评分会话上，同一 HGB 使用有向标志时的 AP 为 0.8025，使用无向共现标志时为 0.6457。两种输入都记录字段共现；区分同一对字段的两个方向，AP 增加 0.1568。

|两种字段的会话级表示|输入列数|AP|
|---|---:|---:|
|无向：同一请求中出现过这两个字段|45|0.6457|
|有向：分别记录两个先后方向是否出现过|90|0.8025|

十个白名单字段构成 45 个无向字段对。对每一对字段，将原有两个方向标志取逻辑或，即得无向标志。如果一场会话的不同请求出现过两种顺序，有向表示保留两个标志，无向表示记为一次共现。没有可解析请求的会话在两种表示中都拒评。

这项事后分析复用原确认集的 4,795 场会话、每场最多 2,048 条原始记录、原五折及固定 HGB 参数。两个模型分别拟合，使用同一批折外会话计算 AP。对会话按折号和类别分层配对重采样 1,000 次，有向减无向的 AP 差值条件 95% 区间为 0.1381 至 0.1756。此区间以本次拟合的折外预测为条件。

数据来源：`runs/pair-control/summary.json` 与 `runs/pair-control/directed-minus-unordered.json`。实现见[配对消融](../agenttrace/pair_control.py)。使用[主研究环境](../README.md)在 attribution/ 下复跑：

```powershell
& $paper -m agenttrace.pair_control runs/cohort2048.npz runs/full-session-pilot.npz --out runs/repro-pair-control
```
