# 写作交接：一份 PCAP 能提供什么来源证据？

本文研究 **Web CTF 解题会话的来源归因**。正类是 Agent 主导的会话，不是恶意请求。可以写“HTTP 请求头结构提供区分两类会话的证据”，不能写“从单个请求认出 LLM”“证明某人使用了 AI”。标签语义由数据提供者说明；索引只有 file、label、fold，没有题目、操作者、框架、采集批次或标注审核记录。

## 正文如何取证

以下四项对应[主实验报告](study.md)的表号。建议结果章节先写表 2 回答任务是否可行，再用表 1 解释特征，最后用表 3、4 讨论代价和边界。本地原始依据在 `runs/paper-study/`；没有该目录时，使用 Git 中的报告快照，不要依据记忆补逐折指标。

|可写入论文的问题|证据及引用位置|不能由此推出什么|
|---|---|---|
|固定观察预算下能否区分来源？|表 2，`confirmation/summary.json`。在未参与选特征的 4,795 场内五折重训。完整 Dist24-HGB 的共同集 AP 0.8236、ROC-AUC 0.8754；可评分 4,549 场。|不是将开发集学到的权重直接迁移到新靶场；不是 5,328 场整场抓包的测试分数。|
|起作用的是哪类输入？|表 1，`development/summary.json`。在 518 场共同可评分开发样本上，完整 AP 0.8161；只删 90 个顺序标志仍为 0.8161；连同箱内及跨箱统计中的显式顺序对一起删，降为 0.7072。|不能说每个标志均必要。删标志后其他列仍编码顺序信息；观测支持信息冗余，而非证明分类器解码了某种 LLM 决策机制。|
|能否减少列数？多看流量是否有益？|表 3，`lock.json` 与 `comparisons.json`。精简模型是同一 HGB，仅取 `ever.*` 90 列（零起始 [2060,2150)）；不是另一个网络。确认集 AP 0.8025，较完整模型低 0.0211，点估计超过预设 0.015 损失容差。EOF 减前缀的 AP 差 +0.0533 是在开发集 518 场上的另一项配对比较。|可写维数减少 95.9%，不能写无损、提取速度提高同等比例或两模型等效。区间以已有 OOF 为条件，不含重新训练和题目聚类误差。|
|客户端是否影响解释？|表 4，`confirmation/dist-hgb/oof.csv` 与缓存中的粗客户端比例。纯浏览器组 AUC 0.776，表中同时列各组样本数与正类比例。|事后分层不是同客户端匹配；没有精确软件版本或同题对照。组间 AP 也随基准正类率改变。|

**数清拒评。** 确认集共有 3,259 场人类、1,536 场 Agent。完整模型可评分 3,148 / 1,401 场，另有 111 / 135 场拒评。验证折以 5% 误报为目标时，测试中误报 148/3,148（4.70%），检出 860/1,401（61.38%）；若对全部 Agent 会话计数，产生正确告警的是 860/1,536（56.0%）。这三个比例不能互换。“共同集 AP”比较同一批文件；“自身 AP”与各低误报工作点按模型自身可用样本计算。

## 哪份成绩用于哪里

|实验及位置|预算 / 样本|角色|

|`paper-study/development-eof` 配对 `development`|EOF 对前缀 / 原 533 场|预算实验。取 `comparisons.json` 内相同样本上的差值，不从两张不同支持集的表相减。|

|`classical-reference` → [传统模型附表](classical.md)|EOF / 原 533 场|10 种算法 × 2 种输入；sklearn 1.8.0 的附表。`classical-matrix` 为 1.9.0 复算，不混用。|

## 容易沿用的旧结论

- **“正式全库尚未执行”已过时。** 全库都有前缀特征，EOF 仅做了开发子集。`runs/prefix.npz` 是零字节残留，不是有效缓存；历史前缀缓存叫 `runs/pilot.npz`，全库前缀叫 `runs/cohort2048.npz`。
- **“AP 0.867”不是摘要的主结果。** 它是 533 场早期 EOF 比较中 Dist24-HGB 的 AP（523 场可评分）。它和表 3 的 EOF AP 0.8694 来自不同运行口径：后者在主研究环境中重算并只取同前缀共有的 518 场。二者都不能替代确认集的 0.8236。
- **“跨题目”“目标侧已隔离”“在线检测”都未经验证。** 抓包没有按靶机地址过滤，内容依赖可见 HTTP/1 请求首部；不解密 TLS。固定包预算不是经过时间，也不是告警延迟。重复向量审计不能替代按题目或运行分组。
