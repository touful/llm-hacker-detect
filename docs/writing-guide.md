# 写作交接：从 HTTP 请求头的有向字段对判断会话来源

有向字段对记录两个 HTTP 头字段是否出现在同一请求中，以及哪个字段在前。Dist24-HGB 将这类特征与字段出现比例、头部风格汇总到会话层面，为每场 Web CTF 解题会话输出来源分数，供调查者排序复核。在确认集 4,549 场可评分会话上，模型的平均精确率（AP）为 0.8236。

## 主结果与证据位置

表号对应[主实验报告](study.md)，运行产物位于 `runs/paper-study/`。

|延长观察范围能增加多少证据？|在开发集两种预算都可评分的 518 场上，读至文件末尾时 AP 为 0.8694，比前缀高 0.0533。|表 3 第二行；`comparisons.json`|

低误报工作点的分母决定它回答哪个取证问题。验证折以 5% 误报为目标；测试折上，完整模型在 3,148 场可评分人类会话中误报 148 场，实际误报率为 4.70%；在 1,401 场可评分 Agent 会话中检出 860 场，检出率为 61.38%。另有 111 场人类和 135 场 Agent 会话拒评。若问题是“所有 Agent 会话中，有多少产生了正确告警”，答案是 860/1,536，即 56.0%。这些计数来自表 2 的同一组折外预测。

## 数据与验证范围

数据提供者将人类主导会话标为 0，将 Agent 主导会话标为 1。索引包含 `file`、`label`、`fold`。主实验对 5,328 个文件各取最多 2,048 条原始记录，在 533 场开发会话上按[既定协议](study-protocol.md)选择特征，在其余 4,795 场内重新训练并验证模型。这是同一采集库内的文件级验证。题目、操作者、框架和采集批次未在索引中标注。

观察范围是抓包内可解析的流量，包含可见的 HTTP/1 首部，未按靶机地址筛选。包数衡量观察预算；客户端分层使用粗类别。表 3 的区间按折和标签重采样会话，以已拟合模型的折外预测为条件。
